# 验收标准

> 说明：本文档是测试编写用例与开发的唯一验收依据。未经产品经理与用户确认，不得修改。
> 标记「待确认」的条目在确认前不作为阻塞项，但需记录为遗留问题。

---

## C 端验收标准

### C-01 首页推荐

| 编号 | 验收标准 |
| --- | --- |
| AC-C-01-01 | 打开首页 2 秒内展示推荐菜品，默认 4 个（菜品库不足时展示全部） |
| AC-C-01-02 | 每张卡片展示：菜品图片、菜名、分类标签、一句话描述 |
| AC-C-01-03 | 每张卡片可单独「加入菜单」，加入后按钮状态变为已加入并显示数量 |
| AC-C-01-04 | 提供「全部加入」按钮，一键把当前推荐的菜加入今日菜单 |
| AC-C-01-05 | 菜品库为空时展示空状态图与「请先到后台添加菜品」提示 |
| AC-C-01-06 | 点击「换一批」后推荐结果发生变化，且不与上一批完全重复 |
| AC-C-01-07 | 连续换一批时，若所有菜品都已展示过，允许从头循环并提示 |
| AC-C-01-08 | 换一批不影响已加入今日菜单的菜品 |
| AC-C-01-09 | 推荐结果不包含已下架菜品（待确认：是否排除最近 7 天已点菜品） |

### C-02 分类浏览

| 编号 | 验收标准 |
| --- | --- |
| AC-C-02-01 | 页面展示全部分类，分类顺序与后台配置一致 |
| AC-C-02-02 | 点击分类后列表只展示该分类的上架菜品 |
| AC-C-02-03 | 「全部」分类展示所有上架菜品 |

### C-03 总菜单（全部菜品：筛选、加入、删除）

| 编号 | 验收标准 |
| --- | --- |
| AC-C-03-01 | 列表默认每页 20 条，滚动到底自动加载下一页 |
| AC-C-03-02 | 全部加载完成后展示「没有更多了」 |
| AC-C-03-03 | 加载中展示骨架屏/loading，加载失败展示重试按钮 |
| AC-C-03-04 | 顶部提供分类 Tab，切换后列表立即筛选为该分类的上架菜品 |
| AC-C-03-05 | 顶部提供搜索框，可按菜名或食材关键词搜索（防抖 300ms） |
| AC-C-03-06 | 卡片默认展示「加入」按钮，点击后加入今日菜单 |
| AC-C-03-07 | 已加入的菜品按钮变为「已在菜单 · N」，并出现「−」按钮 |
| AC-C-03-08 | 点「−」数量减 1；数量减到 0 时从今日菜单移除，按钮回到「加入」 |
| AC-C-03-09 | 在总菜单里加入/删除后，底部悬浮栏与今日菜单页的数量同步更新 |
| AC-C-03-10 | 页面顶部常驻「已选 N 道 · 查看菜单」入口，点击进入今日菜单页 |
| AC-C-03-11 | 刷新页面后，已加入状态仍正确显示（读取 localStorage） |
| AC-C-03-12 | 已下架或已删除的菜品不出现在总菜单列表 |
| AC-C-03-13 | 分类与搜索组合使用时结果同时满足两个条件 |
| AC-C-03-14 | 无菜品时展示空状态与引导提示 |

### C-04 搜索

| 编号 | 验收标准 |
| --- | --- |
| AC-C-04-01 | 输入菜名关键词可模糊匹配到对应菜品 |
| AC-C-04-02 | 输入食材关键词（如「鸡蛋」）可匹配到含该食材的菜品 |
| AC-C-04-03 | 搜索无结果时展示空状态与提示 |
| AC-C-04-04 | 搜索输入防抖 300ms，避免频繁请求 |

### C-05 菜品详情

| 编号 | 验收标准 |
| --- | --- |
| AC-C-05-01 | 详情展示：大图、菜名、分类、描述、食材列表 |
| AC-C-05-02 | 辣度与烹饪时长若已配置则展示，未配置则不展示该字段 |
| AC-C-05-03 | 详情页提供「加入今日菜单」按钮 |
| AC-C-05-04 | 已下架或被删除的菜品不可访问详情，返回提示 |

### C-06 今日菜单（点菜车）

| 编号 | 验收标准 |
| --- | --- |
| AC-C-06-01 | 底部悬浮栏实时显示已选菜品数量 |
| AC-C-06-02 | 加入菜品后悬浮栏数量 +1，出现动画提示 |
| AC-C-06-03 | 重复加入同一菜品，数量累加，列表不出现重复行 |
| AC-C-06-04 | 菜单页逐条展示：图片、菜名、数量、小计 |
| AC-C-06-05 | 数量可在 1~99 之间增减，减到 1 时不能再减（需删除） |
| AC-C-06-06 | 可单条删除，删除后数量统计同步更新 |
| AC-C-06-07 | 「清空」需二次确认，确认后菜单为空 |
| AC-C-06-08 | 菜单数据写入 localStorage，刷新页面后不丢失 |
| AC-C-06-09 | 菜单为空时展示空状态与「去首页看看推荐」入口 |

### C-07 提交菜单

| 编号 | 验收标准 |
| --- | --- |
| AC-C-07-01 | 菜单为空时提交按钮禁用或提示「请先选择菜品」 |
| AC-C-07-02 | 提交时按钮进入 loading，禁止重复点击 |
| AC-C-07-03 | 提交成功后展示成功页：日期、菜品清单、菜品数量 |
| AC-C-07-04 | 提交成功后清空本地今日菜单 |
| AC-C-07-05 | 提交失败展示错误提示，且本地菜单数据不丢失 |
| AC-C-07-06 | 同一天可提交多次，每次生成独立记录，互不覆盖 |

### C-08 历史菜单

| 编号 | 验收标准 |
| --- | --- |
| AC-C-08-01 | 按日期倒序展示历史记录 |
| AC-C-08-02 | 每条记录展示日期、菜品数量、前 3 个菜名 |
| AC-C-08-03 | 点击可展开查看完整菜品列表（含图片与数量） |
| AC-C-08-04 | 支持下拉加载更多，每页 20 条 |
| AC-C-08-05 | 菜品已被删除时，历史记录仍展示当时保存的名称与图片快照 |
| AC-C-08-06 | 无历史记录时展示空状态 |

## 后台验收标准

### A-01 登录

| 编号 | 验收标准 |
| --- | --- |
| AC-A-01-01 | 输入正确账号密码可登录并跳转首页 |
| AC-A-01-02 | 账号或密码错误时提示「账号或密码错误」，不区分具体是哪一项错 |
| AC-A-01-03 | 未登录访问任意后台页面自动跳转登录页 |
| AC-A-01-04 | 可退出登录，退出后 Token 失效 |
| AC-A-01-05 | 密码在数据库中以哈希形式存储，不得明文（待确认：加密算法） |

### A-02 菜品管理

| 编号 | 验收标准 |
| --- | --- |
| AC-A-02-01 | 菜品列表分页展示，每页 20 条，展示缩略图、菜名、分类、状态、排序、更新时间 |
| AC-A-02-02 | 支持按分类筛选、按名称模糊搜索、按上下架状态筛选 |
| AC-A-02-03 | 新增菜品必填：名称、分类；主图至少 1 张（待确认：主图是否必填） |
| AC-A-02-04 | 描述、辣度、烹饪时长、食材为选填 |
| AC-A-02-05 | 食材支持从已有食材选择，也支持自由输入新食材（输入后自动创建） |
| AC-A-02-06 | 新增成功后列表可见该菜品，排序按排序值升序 |
| AC-A-02-07 | 名称重复时给出提示（待确认：是否允许重名） |
| AC-A-02-08 | 编辑菜品可修改全部字段并保存 |
| AC-A-02-09 | 删除需二次确认 |
| AC-A-02-10 | 删除为逻辑删除，历史菜单记录仍可展示该菜品快照 |
| AC-A-02-11 | 已删除菜品不出现在后台列表与 C 端 |
| AC-A-02-12 | 上架/下架可一键切换，无需保存 |
| AC-A-02-13 | 下架后 C 端列表、搜索、推荐均不再出现该菜品 |
| AC-A-02-14 | 排序值可调整，值越小越靠前 |

### A-04 分类管理

| 编号 | 验收标准 |
| --- | --- |
| AC-A-04-01 | 支持分类的增删改查 |
| AC-A-04-02 | 分类名称不可重复 |
| AC-A-04-03 | 分类可设置排序值，C 端按该顺序展示 |
| AC-A-04-04 | 停用分类后 C 端不展示该分类及其菜品 |
| AC-A-04-05 | 分类下仍有上架菜品时，删除需二次确认并提示影响范围（待确认：是否允许直接删除） |

### A-05 图片上传

| 编号 | 验收标准 |
| --- | --- |
| AC-A-05-01 | 支持 jpg / png / webp 格式 |
| AC-A-05-02 | 单张图片 ≤ 5MB，超出时前端拦截并提示 |
| AC-A-05-03 | 上传后展示预览图，可删除重传 |
| AC-A-05-04 | 上传接口需要管理员鉴权，未登录上传返回 401 |
| AC-A-05-05 | 后端二次校验文件类型与大小，非法文件返回明确错误 |
| AC-A-05-06 | 上传成功返回可访问 URL 并保存到菜品记录 |

### A-06 点菜记录

| 编号 | 验收标准 |
| --- | --- |
| AC-A-06-01 | 按日期倒序展示菜单记录 |
| AC-A-06-02 | 可按日期范围筛选 |
| AC-A-06-03 | 点击查看详情：日期、菜品清单、数量 |

## 后端接口通用验收标准

| 编号 | 验收标准 |
| --- | --- |
| AC-S-00-01 | 所有接口返回统一结构：`{ code, message, data }` |
| AC-S-00-02 | 业务失败返回明确错误码与中文提示，不使用 HTTP 500 掩盖业务错误 |
| AC-S-00-03 | 参数校验失败返回 400 并说明具体字段 |
| AC-S-00-04 | 未授权访问后台接口返回 401 |
| AC-S-00-05 | 分页接口统一使用 `page` 与 `pageSize` 参数，返回 `total` |
| AC-S-00-06 | 接口异常记录日志，日志不包含密码等敏感信息 |

## 非功能验收标准

| 编号 | 验收标准 |
| --- | --- |
| AC-N-01-01 | 在 375px 宽度屏幕下页面无横向滚动、无元素重叠 |
| AC-N-01-02 | 主要按钮点击区域不小于 44×44px |
| AC-N-01-03 | 在微信内置浏览器中可正常打开与使用 |
| AC-N-02-01 | 接口失败时展示 toast 提示，不白屏、不暴露堆栈 |
| AC-N-02-02 | 图片加载失败展示占位图 |
| AC-N-02-03 | 弱网下页面有加载状态提示 |
