# 项目章程

## 项目名称

家庭点菜小程序（项目代号：cooking）

## 一句话定义

一个给家庭用的「今天吃什么」点菜工具：家人从菜品库里点菜，生成当日菜单；管理员在后台维护菜品、图片、描述和食材信息。

## 项目背景

家里每天都要决定「今天吃什么」，决策成本高、容易重复。希望通过一个轻量工具：

1. 把家里的常做菜品沉淀成一个菜品库；
2. 每天打开就能看到推荐菜单，不用从零开始想；
3. 像在饭店点菜一样，把想吃的菜加进「今日菜单」；
4. 保留历史菜单，方便回顾和复用。

## 项目目标

| 编号 | 目标 | 衡量方式 |
| --- | --- | --- |
| G-01 | 家庭成员能在手机上 1 分钟内完成一次点菜 | C 端从打开到提交菜单的操作步骤不超过 5 步 |
| G-02 | 菜品库可由管理员自助维护，不需要改代码 | 后台可完成菜品的增删改查、上下架、图片上传 |
| G-03 | 每天能自动给出一份可执行的菜单建议 | 首页展示推荐菜单，支持「换一批」 |
| G-04 | 历史菜单可回溯 | 可查看最近 30 天的点菜记录 |

## 目标用户

| 角色 | 说明 |
| --- | --- |
| 家庭成员（C 端用户） | 家里做饭的人 / 一起吃饭的人，负责浏览菜品、点菜、查看历史 |
| 管理员（后台用户） | 维护菜品库的人，负责录入菜品、分类、图片、描述、食材 |

> 已确认（Q-02）：C 端**免登录**，打开即用，不区分家庭成员账号，不需要多人协作。

## 技术栈（已确认）

| 层次 | 选型 | 状态 |
| --- | --- | --- |
| C 端前端 | Vue 2 + Vant 2（移动端 H5 网页） | 已确认 |
| 管理后台前端 | Vue 2 + Element UI 2 | 已确认 |
| 后端 | Node.js + **Express** | 已确认 |
| ORM | Sequelize 6 + mysql2 | 已确认（技术设计阶段定，可调整） |
| 数据库 | **MySQL 8** | 已确认 |
| 图片存储 | 后端本地磁盘 + 静态目录 | 已确认（后续可换对象存储） |
| 部署 | 本机 / 局域网单机，Docker Compose | 已确认（第一版） |

> 已确认（Q-01）：C 端是**移动端 H5 网页**（手机浏览器 / 微信内置浏览器打开），不是微信小程序原生，因此 Vue 2 + Vant 方案成立。

## MVP 范围（第一版）

包含：

1. 首页推荐菜单（**4 个菜**）+ 换一批
2. **总菜单（全部菜品）：分类筛选 + 搜索 + 加入 + 直接删除**
3. 菜品详情（图片、描述、食材）
4. 点菜车（今日菜单）：加菜、减菜、删除、清空
5. 提交今日菜单并生成记录
6. 历史菜单查看
7. 后台登录
8. 后台菜品管理（CRUD、上下架）
9. 后台分类管理
10. 后台图片上传
11. 后台点菜记录查看

不包含（明确砍掉，后续版本再说）：

- 用户注册 / 家庭群组 / 多人协作
- 支付、计价、结算
- 复杂的智能推荐算法（本版用规则推荐）
- 营养计算、热量统计
- 菜品做法步骤视频
- 评论、评分、收藏、点赞
- 消息通知推送
- 数据大屏与复杂报表
